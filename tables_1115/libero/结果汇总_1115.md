# LIBERO / LIBERO-PRO 四方法对比:结果汇总

实验时间:2026-11-12 至 11-15。

## 1. 实验设置

四个方法(Ours、FSM、CoRAL、L2R)都由同一个大模型写控制内容,不用专家规格,下层是同一个 MPPI 规划器。

| 项目 | 设置 |
|---|---|
| 大模型 | claude-haiku-5-5,思考强度 low |
| 物体信息 | 仿真真值位姿和包围盒,不经过相机感知 |
| 步数上限 | 每局 600 步 |
| 初始状态 | 套件自带的固定初始状态 |
| 成功判定 | LIBERO 环境判定任务完成 |
| 局数 | 正式每任务 50 局;试跑每任务 2 局 |
| 基线 | FSM、CoRAL、L2R 是我们按各自论文接口适配到 LIBERO 的实现 |

各轮的差别:

- 原 LIBERO 正式:两个 object 任务用高物体抓取点(四个方法共用),Ours 在这两个任务上用第 4 版提示词,其余都是第 3 版。
- LIBERO-PRO(试跑和正式):所有任务都用高物体抓取点,Ours 用第 4 版提示词,其余方法第 3 版。
- 原 LIBERO 试跑:Ours、FSM、L2R 用的是 medium 思考强度,CoRAL 是 low。
- 两轮正式的 5 个任务都是按对应试跑的结果挑选的。

## 8. 使用这些数字时要注意

- 四个方法用的是真值位姿,和以相机图像为输入的 VLA 结果不能直接比。
- 两轮正式的 5 个任务都是按试跑结果挑的,未经挑选的水平看第 5 节。
- 第 4 版提示词是看过原 LIBERO 正式结果后只对 Ours 做的修订。
- 基线是我们适配的实现,不是原作者的代码。
