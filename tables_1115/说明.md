# 11 月实验:可用来画表的数据

打包日期:2026-11-15。范围是 11 月 1 日以来的全部实验。实验设置和结果的文字说明见同目录的 `11月实验汇总_1115.md`;LIBERO 部分更详细的设置见 `libero/结果汇总_1115.md`。

所有 CSV 都是 UTF-8(带 BOM),可直接用 Excel 打开。除了下面标了"手工录入"的几张表,其余都是用脚本从原始结果文件里抽出来的。

## flexbench/ —— Flex-Bench 仿真基准

注意:除 π0.5 两行外,这些实验是 10 月 27 日跑完的,11 月 9 日补算了严格判定。

| 文件 | 内容 |
|---|---|
| `success_by_scene.csv` | 每个方法行 × 每个场景(以及合计 ALL)的严格判定成功数、放宽判定成功数、局数、到达目标的局数。只统计可行且没有报错的题。 |
| `pass_by_requirement_class.csv` | 每个方法行在 15 类要求上各自的通过局数和涉及局数。 |
| `episodes.csv` | 每局一行(5,508 局):题号、场景、方法行、是否可行、是否报错、两种判定的成功与否、是否到达目标、最终误差、涉及的要求类别、大模型调用次数等。 |
| `problems.csv` | 每个场景生成的题数和可行题数。 |
| `excluded_error_episodes.csv` | 因报错被排除的局数(按方法行和场景)。 |
| `vla_training_data.csv` | π0.5 训练示范的局数和覆盖的题数。 |

方法行的名字:`ours` / `wp` / `api` / `code` 是专家规格渲染到四种接口;`llm_*` 是大模型写;`llm_l2r` 是忠实复现的 L2R(只跑了 414 局);`vla_pi05_ck25000`、`vla_pi05_ck29999` 是 π0.5 的两个存档。

## real/ —— 真机实验

| 文件 | 内容 |
|---|---|
| `E1_formal/per_stroke.csv`、`metrics.json` | E1 正式局(11-07)每笔的路径误差、覆盖率、力、接触高度,以及整局指标。 |
| `E3_formal/per_stroke.csv`、`metrics.json`、`joint3_height.csv` | E3 正式局(11-07)每笔指标、整局指标、关节 3 高度随时间的曲线。 |
| `E2_runs.csv` | E2 四局(11-05)的推距、放置误差、倾斜、外力、耗时。**手工录入**,数字取自各局的 `task.json` 和 11-09 的真机报告。 |
| `formal_runs_from_report_1109.csv` | 11-09 真机报告里的四个正式局清单(指令、规格来源、参数、结果)。 |
| `table_writing_runs.csv` | 桌面写字 11-07 至 11-14 的每次运行(49 次,含真机和假机):写的字、是否成功、中止原因、用时、轨迹误差、压力、触纸偏移、保护触发次数。 |
| `baseline_fake_runs.csv`、`baseline_fake_per_stroke.csv` | 三行基线(L2R、直接轨迹、CaP-X)在本地假机上的 6 次运行和每笔指标。没有真机数据。 |
| `run_counts.csv` | 各类真机实验的真机 / 假机运行次数和成功次数。**手工录入**。 |

## sim_rebuild/ —— E1 / E3 的 MuJoCo 重建(11-07)

| 文件 | 内容 |
|---|---|
| `runs.csv` | 77 次运行:完成笔画数、口令后完成笔画数、关节 3 误差、最大倾斜、最大力、碰撞样本数、大模型及调用次数。最终配置是 `F1*` / `F3*`(手写规格)和 `L1*` / `L3*`(大模型写规格),其余是开发迭代。 |
| `per_stroke.csv` | 每次运行每笔的覆盖率和路径误差。 |

`spec_source_guess_from_name` 一列是按运行名首字母推断的(L 开头记为大模型),不是文件里的字段。

## pen_tracking/ —— 笔的视觉跟踪(11-07 至 11-09)

| 文件 | 内容 |
|---|---|

## libero/ —— LIBERO 与 LIBERO-PRO 四方法对比(11-12 至 11-15)

| 文件 | 内容 |
|---|---|
| `totals.csv` | 每轮实验每个方法的成功局数、总局数、成功率。 |
| `per_task.csv` | 每个任务每个方法的成功局数、总局数、成功率、成功局步数中位数。 |
| `episodes.csv` | 每局一行(3,397 局)。 |
| `pro_formal_failure_types.csv` | LIBERO-PRO 正式的失败局分类(从没夹住、夹了别的物体、夹住没放下、松开后没判成功)。 |
| `llm_usage.csv` | 各轮各方法的大模型调用次数、token 用量和估算花费。Ours 的花费是按每次调用的实测值推算的。 |
| `vla_public_numbers_suite_avg.csv` | VLA 在 LIBERO 四个套件上的公开成功率。**手工录入**,不是我们跑的。 |
| `vla_public_numbers_our_tasks.csv` | VLA 在我们选的 10 个任务上的公开逐任务成功率。**手工录入**,不是我们跑的,来源见表内。 |
| `结果汇总_1115.md` | LIBERO 部分的设置和汇总表。 |

`experiment` 一列的取值:`libero_formal`、`libero_pro_formal`、`libero_pilot`、`libero_pro_pilot`,以及两个被替换掉的中间版本 `libero_formal_old_center_grasp`、`libero_formal_old_ours_rev3`。

## 使用时注意

- 真机 E1 / E2 / E3 是挑出的成功局,不是成功率。
- 桌面写字的轨迹误差是按关节角推算的,不是量墨迹。
- Flex-Bench 是单种子,放宽判定是事后定的。
- LIBERO / LIBERO-PRO 用真值位姿,正式的任务是按试跑挑的。
- VLA 的公开数字口径和我们不同,不能直接放进同一张对比表。
