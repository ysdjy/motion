# 截图清单

- 截图全部是视频原帧（OpenCV 按帧号读出后直接保存为 PNG，不缩放、不裁剪、不加标注）或腕部相机原图（直接复制）。
- 画面左上角的时间是录像程序本身叠加的墙钟，不是后加的。
- 时间点：
  - 实验一、实验三：按 `specs.json` 里每个规划窗口的（墙钟，t）做线性拟合，再与录像的 `.timestamps.jsonl` 逐帧对时，误差小于 0.1 s。
  - 实验二：按 `replay/live/*.json` 里各阶段第一条记录的墙钟对时。
  - 写字核对组：按目录名估计，误差约数秒。
- 完整的对时记录见 `figures/frames_log.json`，生成脚本是 `work/extract_frames.py`。
